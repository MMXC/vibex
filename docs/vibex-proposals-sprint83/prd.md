## P001: 画布版本历史时间轴

### 概述
为画布版本分支管理（E1）添加时间轴可视化，支持分支创建/合并时间展示。

### 用户故事
- 作为用户，我希望看到画布版本的历史时间轴，以便快速定位历史版本

### 验收标准
- [ ] 时间轴组件显示所有分支的创建和合并节点
- [ ] 点击时间轴节点可跳转到对应版本
- [ ] 时间轴支持缩放（近/远视角）

### 页面集成
- `DDSCanvasPage.tsx` — 侧边栏历史面板

## P002: 导入链接画布

### 概述

### 用户故事
- 作为用户，我希望通过链接导入他人的画布，以便快速复用内容

### 验收标准

- [ ] 导入时展示预览 + 确认对话框
- [ ] 导入后保留原始画布归属信息

### 页面集成
- `DDSToolbar.tsx` — 导入菜单增加"链接导入"选项

## P003: 协作者冲突确认反馈

### 概述
冲突自动解决后增加用户确认步骤，提升冲突处理的透明度。

### 用户故事
- 作为协作者，我希望在冲突被自动解决后看到确认提示，以便我知道发生了什么

### 验收标准
- [ ] Auto-resolve 完成后弹出确认 Toast（3秒自动消失）
- [ ] Toast 显示使用的策略（Keep Mine / Keep Theirs / Auto-merge）
- [ ] 用户可点击 Toast 查看详细变更

### 页面集成
- `DDSCanvasPage.tsx` — Toast 通知区域
