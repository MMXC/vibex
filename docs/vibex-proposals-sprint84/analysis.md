## 二、基于 S83 交付的 S84 功能缺口分析

### 2.1 数据管理：画布版本能力深化

S83-E1 完成了时间轴可视化和分支节点展示，但以下能力缺失：

- **版本对比（diff）**：用户无法直观比较两个版本之间的内容差异
- **分支合并 UI**：支持用户选择源分支并执行合并，带预览
- **版本分支删除/归档**：长期积累的分支需要管理能力

### 2.2 协作体验：实时存在感和 WebSocket 可靠性

S83-E3 实现了冲突确认反馈，但协作者实时状态仍不完整：

- **在线协作者头像/光标**：显示谁正在编辑同一画布
- **WebSocket 重连优化**：断线重连后状态同步的空白窗口需要消除
- **协作者编辑锁**：防止多人同时编辑同一节点导致的 UX 混乱
- **协作会话历史**：查看谁在何时做了什么修改

### 2.3 模板系统：从标签到发现和分享

S84-E4 实现了标签系统，但模板生态不完整：

- **模板搜索增强**：支持按名称/标签全文搜索
- **模板预览**：大图预览 + 缩略图懒加载
- **模板收藏**：用户可收藏常用模板
- **模板评论/评分**：社区反馈机制

### 2.4 画布 UX：从时间轴到多维导航

时间轴组件（E1）已经可用，需要向上延伸：

- **快速跳转面板**：Ctrl+P 风格的画布节点快速切换
- **画布书签/收藏**：快速访问常用画布
- **缩略图概览模式**：鸟瞰画布整体结构的缩略图视图
- **画布复制/模板化**：一键将当前画布保存为模板

### 2.5 UI 增强：工具栏、对话框、通知系统

基础 UI 交互层需要系统性提升：

- **富文本编辑工具栏**：支持更丰富的文本样式和格式化
- **对话框增强**：统一的对话框系统，支持拖拽和调整大小
- **通知中心**：聚合所有系统通知，支持历史记录
- **键盘快捷键体系**：标准化的全局快捷键配置

## 三、技术风险评估

| 风险 | 影响 | 缓解策略 |
|------|------|----------|
| WebSocket 协作大规模并发 | 高 | 限制协作者数量（≤10），操作队列化 |
| 版本 diff 大数据量渲染 | 中 | 虚拟化列表 + 分片 diff |
| 模板缩略图存储成本 | 低 | CDN + WebP 压缩 |
| 全局快捷键与浏览器冲突 | 中 | 可配置快捷键方案 |
