## 2. 提案详情

### P001: 全局键盘快捷键系统

**问题描述**:

当前 VibeX 缺少统一的键盘快捷键系统。用户每次操作都需要使用鼠标，效率低。特别是高频操作（撤销/重做、新建节点、切换 Tab、生成代码）在 DDSCanvasPage 中完全依赖点击，缺乏快捷键。

**影响范围**:

- 所有使用 DDSCanvasPage 的用户
- 严重影响高频用户的产品体验
- S36-E4 已实现撤销重做 Toolbar 按钮，但快捷键缺失

**验收标准**:

- [ ] `Ctrl+Z` 触发 undo
- [ ] `Ctrl+Shift+Z` / `Ctrl+Y` 触发 redo
- [ ] `Ctrl+N` 新建节点
- [ ] `Ctrl+G` 触发代码生成
- [ ] `Tab` / `Shift+Tab` 切换 Tab
- [ ] `Escape` 取消选择
- [ ] 快捷键在 DDSCanvasPage 全局生效
- [ ] Help overlay（`?` 键）显示所有快捷键列表

### P002: Canvas 导出增强（PDF + 图片格式）

**问题描述**:

当前导出功能仅支持 PNG，缺少 PDF 和其他常见图片格式支持。

**影响范围**:

- 所有有导出需求的用户
- PDF 是企业场景的标准交付格式

**验收标准**:

- [ ] 支持导出 PDF
- [ ] 支持导出 JPG
- [ ] 支持导出 SVG
- [ ] 导出文件命名规范化

### P003: Error Boundary 错误恢复机制

**问题描述**:

DDS 画布组件缺少 Error Boundary，导致任意组件崩溃时整个页面崩溃。

**影响范围**:

- 所有用户，崩溃后无法恢复

**验收标准**:

- [ ] 单个组件崩溃不影响其他组件
- [ ] 崩溃后有恢复按钮
- [ ] 崩溃日志上报

### P004: User Preferences 持久化系统

**问题描述**:

用户的画布偏好（默认视图、最近打开、快捷键自定义）未持久化，刷新页面后丢失。

**影响范围**:

- 所有用户，每次访问需要重新配置

**验收标准**:

- [ ] 画布偏好存储到 localStorage
- [ ] 刷新页面后偏好恢复
- [ ] 偏好同步到云端（可选）

### P005: Design Token 主题系统

**问题描述**:

品牌定制需要主题系统，支持颜色/字体/间距的品牌级配置。

**影响范围**:

- 企业品牌定制用户

**验收标准**:

- [ ] 支持自定义主题变量
- [ ] 主题切换无刷新
- [ ] 主题预览能力
